How To Run The Course Platform

Use this page when you are preparing, teaching, and reviewing a class session.

5 steps
Start here

The short version

For each lecture, open Classroom Mode, choose the lecture, show the QR code, run a short quiz or pulse, send students to the mission, then collect the exit ticket. After class, open Teacher Insights to see what needs review.

Visual workflow

What happens in one class

1

Prepare

Choose the lecture in Classroom Mode. Open the deck, mission, and quiz console.

2

Project

Show the QR code or copy the student link. Students use their phones.

3

Pulse

Ask a live question, let pairs discuss, reveal the answer, and debrief the reasoning.

4

Practice

Send students to the mission, case, concept map, or quiz for a short activity.

5

Review

Collect exit tickets. Use Teacher Insights to decide what to revisit next class.

Before class

Checklist

  1. Open Classroom Mode.
  2. Select the lecture you are teaching.
  3. Open the Deck and Playbook links from Classroom Mode.
  4. Open the Quiz console and press Start when you want a live quiz.
  5. Keep your Teacher PIN ready for Supabase summaries.
During class

Class rhythm

  1. Explain one concept for a few minutes.
  2. Use the live pulse in Classroom Mode.
  3. Ask students to discuss the answer with a neighbor before you reveal it.
  4. Run a quiz when you want individual evidence.
  5. Use the timer for 2, 5, 8, or 12 minute activities.
After class

Review loop

  1. Open Teacher Insights.
  2. Enter the Teacher PIN and load reflections.
  3. Look at low-confidence tickets and muddy points.
  4. Load the semester participation view when you want student-level signals.
  5. Export CSVs from Teacher Insights, Quiz Console, or Assessment Studio when needed.
Important habit

Student identity

Ask students to use the same Student ID in quizzes, exit tickets, and portfolio submissions. This is what lets the teacher tools match records across the semester.

Recommended classroom wording: “Use your official student ID every time. Do not invent a nickname for the ID field.”

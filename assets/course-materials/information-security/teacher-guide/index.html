How To Run The Course App

Prepare, teach, and grade every class from one authenticated app.

5 steps
Start here

The short version

Sign in to the Course App with your @tec.mx account. Before the semester: create sections, import your roster, author content and quizzes, and set gradebook categories. Each class: release the lecture, then launch the end-of-class quiz live (share the QR/link). After class: review insights, student records (with integrity flags), and the gradebook.

Before the semester

Set up once

  1. Create your sections.
  2. Import your roster (institutional emails).
  3. Author lectures and quizzes in the Content Library.
  4. Set gradebook categories and weights.
  5. Create class sessions.
During class

Run it

  1. Release today's lecture for the right section and session.
  2. Teach; keep it interactive with quick questions.
  3. Launch the quiz live and show the QR / join link.
  4. Watch submissions arrive; close it when time is up.
After class

Review & grade

  1. Open Insights for topic-level signals.
  2. Open Student Records — includes integrity flags.
  3. Adjust, lock, and export in the Gradebook.
  4. Check the Audit Log for sensitive actions.
Academic integrity

Quiz safeguards

Graded quizzes are scored on the server (answers never reach the browser), delivered live and timed with one attempt, and each attempt records tab-switching, paste, and timing plus a hidden AI tripwire. Suspicious attempts are flagged in Student Records and the Audit Log. Keep in-class quizzes low-stakes and reserve high-stakes assessment for controlled settings — that is the most reliable safeguard.
